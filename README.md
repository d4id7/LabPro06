# ПР6. Ответы на вопросы

В процессе работы мне пришлось перемещать папки с проектом в другие, из-за этого коммиты, сделанные до дополнительных заданий, не стёрлись

1. void-метод не возвращает никакого значения во время вызова метода, он просто выполняет каки-то действия (например, печатает текст)
2. После срабатывания return метод завершает свою работу (все последующие строчки кода не учитываются), а метод возвращает значение, написанное после return
3. Перегрузка методов означает наличие в программе двух и более методов с одинаковым именем, но разным типом данных параметров или разным количество параметров. Компилятор различает их по типу данных или количеству аргументов, передаваемых в метод во время его вызова
4. Нельзя, так как компилятор не сможет понять, какой именно метод ему стоит вызывать
5. Логично разбить большой код на два отдельных метода при регистрации пользователя: первый метод - валидация введённого пользователем, а второй создание записи в базе данных
6. Когда метод вызывает внутри себя другой метод, это помогает сократить код и улучшить его чтение. Например, в итоговой работе, я написал метод вычисляющий наибольшее значение из двух чисел, а потом использовал его в методе, вычисляющем наибольшее значение из трёх чисел
